# ThinkOrSwim

Tools and insights into the Think or Swim (desktop) trading application, now owned by Schwab. This repo is intended to contain thrinkscripts, information on preference files, optimizations, etc.

## Table of Contents

1) [ColorPreferences.md](ColorPreferences.md) documentation for hand-editing the ToS color schemes.

2) [DarkModeKeys.md](DarkModeKeys.md) documentation for dark mode keys-to-elements.

2) [LightMode.md](LightMode.md) documentation for light mode.

## ThinkOrSwim Shared Pallettes

[**Andy Dark**](http://tos.mx/!Dnb4pVac) Personal Dark Mode scheme for ThinkOrSwim:

    http://tos.mx/!Dnb4pVac

Import by pasting that URL into the "Open Shared Item" in the upper right setup menu.

There are a few colors I haven't mapped yet, like the blue links that are too dark on the TradeLog page... Otherwise, scheme is intended to improve legibility when bleary-eyed at 6:30 in the morning.
